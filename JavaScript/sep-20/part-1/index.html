Topic: JavaScript Variables & Datatype

What is a variable?

A variable is a named container that holds a value. It can be used to store data in a program.

What's a datatype?

A datatype describe the type of data.

What's the difference between data & information?

Raw or unprocessed form of information is called data. Whereas information is the processed data.

What are the types of data?

There are many types of data in most of the programming languages such as:

  • Primitive datatype (pre defined)
  • Non-primitive datatype (user defined datatype)
How many datatype are there in JavaScript?

There are 8 datatype in JavaScript

  1. Number: Integer and Float(decimal) values
  2. String: Collection of one or more than one character
  3. Boolean: True or False
  4. Null: Empty value
  5. Undefined: Value is not defined
  6. Symbol: A special data type that is used to create unique identifiers
  7. BigInt: A datatype that can hold large integer values
  8. Object: A collection of key-value pairs used to store properties and methods.
What are the things we should know while working with variables in JavaScript?

When working with variable we should remember that JavaScript is a dynamically typed (loosely typed) language. Means once you create/declare a variable we can assign any type of value.

There are two limitations on variable names in JavaScript:

  1. The name must contain only letters, digits, or the symbols $ and _
  2. The first character must not be a digit.

Declaration means creating a variable; So, to declare a variable we use one of the following keyword.

  • var
  • let
  • const
to declare a variable we use one of the following keyword.

How do you declare a variable in JavaScript?

You can declare a variable by using the var, let, or const keyword.

What is the difference between var, let, and const?

They have different scopes and can be used to declare different types of variables.
